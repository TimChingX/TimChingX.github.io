## 添加新作品

1. 在 `works/` 下新建一个文件夹，放入作品的 `index.html` 和封面图 `cover.jpg`（1600×900，16:9）。
2. 在首页 `index.html` 的「作品」部分复制一段 `<article class="work">`，改成新作品的类别小字（如“网页工具”“网页演示”“Excel 表格”）、标题、简介、上线日期（`<time>` 里写成 `2026.10.22` 这种格式）和链接。作品按日期从新到旧排，新作品放在对应的位置。首页是社论式风格，和央玺花园演示同一套：象牙纸色底、暖黑字、衬线标题、等宽日期、陶土橘类别小字，细线分隔，不用阴影，不跟随深色模式。页面至少一屏高，页脚贴在屏幕底部。手机上作品排成细线分隔的列表（左边 16:9 封面，右边类别、标题、日期，不显示简介）；平板上列表行加大并显示两行简介；电脑上排成三张并排的燕麦色卡片，文字在上、截图从卡片底边升起，三张卡的标题、日期线和截图上下对齐。标题要一行放下。封面按 16:9 整张显示，不裁切，所以封面图要做成 16:9。作品卡不放数字统计和署名，只显示日期。
3. 在新作品页的 `</body>` 前加一行 `<script defer src="https://events.vercount.one/js"></script>`，这一页的访问才会计入全站访问统计。
4. 首页的标题衬线字体是按现有标题生成的子集（`assets/home-serif-500.woff2`，思源宋体 Medium）。新作品标题里如果有子集里没有的字，要把所有标题的字合起来重新生成这个子集，否则这些字会退回系统宋体。简介、类别小字用系统字体（苹果设备上是苹方，Windows 上是微软雅黑），不用另外处理。
