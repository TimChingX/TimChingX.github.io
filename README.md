| 作品 | 说明 |

## 目录

- `index.html`：作品集首页
- `works/yangxi-garden/`：演示页面及封面图
- `assets/`：首页用到的字体（思源宋体子集）

## 添加新作品

1. 在 `works/` 下新建一个文件夹，放入作品的 `index.html` 和封面图 `cover.jpg`（建议 1600×900）。
2. 在首页 `index.html` 的「作品」部分复制一段 `<article class="work">`，改成新作品的标题、说明和链接。

本页为个人作品展示，非企业官方网站。
