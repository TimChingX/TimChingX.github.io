## 添加新作品

1. 在 `works/` 下新建一个文件夹，放入作品的 `index.html` 和封面图 `cover.jpg`（建议 1600×900）。
2. 在首页 `index.html` 的「作品」部分复制一段 `<article class="work">`，改成新作品的类别小字（如“网页工具”“网页演示”“Excel 表格”）、标题、简介、上线日期和链接，放在想要的位置。首页是苹果风格：浅灰底、毛玻璃导航条、两色大标题。手机上作品排成 iOS“设置”式的分组列表（左边 4:3 封面，右边类别、标题、日期，不显示简介）；平板上列表行加大并显示两行简介；电脑上排成三张并排的白色卡片，文字在上、截图从卡片底边升起。标题里的 `<br>` 是手机和电脑上的换行位置，平板上会自动忽略。封面会裁成 4:3，主体不在中间的封面在 `<article>` 上加 `style="--pos:…"`（如 `--pos:85% 0`）指定保留哪边。作品卡不放数字统计和署名，只显示日期。
3. 在新作品页的 `</body>` 前加一行 `<script defer src="https://events.vercount.one/js"></script>`，这一页的访问才会计入全站访问统计。
4. 首页用系统字体（苹果设备上是苹方 / SF，Windows 上是微软雅黑），新标题不用另外生成字体子集。`assets/` 里的思源宋体子集现在只给维修台账作品页用。

本页为个人作品展示，非企业官方网站。
